# Project:

- Mockup-Login

# Goal:

- A practical portfolio project for authentication testing and dashboard mocking.

# Core Features:

- **Current State:**
  - ระบบ Backend และ API ทำงานได้สมบูรณ์ (รองรับ Auth Flow)
  - หน้า Frontend สำหรับ Authentication (Login/Register) เสร็จสิ้น โดยสามารถ Submit Form, Validate ข้อมูล, และนำ API มาต่อกัน (Integration) ได้สำเร็จ
  - ข้อมูล User และ Token ถูกจัดเก็บไว้ใน Memory ฝั่ง Client อย่างถูกต้อง
  - เตรียมพร้อมสำหรับการสร้างหน้า Dashboard และปิดกั้นการเข้าถึง (Protected Routes) ใน Phase 6
